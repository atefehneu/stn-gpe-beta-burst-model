# stn-gpe-beta-burst-model
Simulation and analysis code for a cortex–GPe–STN computational model investigating beta burst dynamics and deep brain stimulation responses in Parkinson’s disease.

This repository contains code associated with a manuscript currently under peer review. 
The repository will be updated with the final version upon publication.

You can use this package for:

i. Producing a network of GPe-STN with one- or two-way delayed of synaptic currents.

ii. Checking the effect of synaptic delays on bursting behavior of STN.

iii. Checking the effect of cortex and DBS on bursting behavior of STN.

*** Run the ‘.ode’ file after installing ‘XPPAUT’ to test how bursting profiles of STN could be affected by synaptic delays. 

*** Run the script ‘.m’ file to see the figures are reported in our paper. 

***Since the simulation data are large (2.7 GB), and uploading files larger than 25MB is not possible, contact me to provide you with datasets, if you want to test the .m code.
